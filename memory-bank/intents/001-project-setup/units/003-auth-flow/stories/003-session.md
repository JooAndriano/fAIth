# Story 003 — Session + Sign-out

**Intent:** 001-project-setup
**Unit:** 003-auth-flow
**Story:** 003-session
**Status:** Draft

## User Story
As a user, I want my signed-in state to persist and be able to sign out.

## Acceptance Criteria
- Signed-in state persists after app restart.
- Sign-out clears session and returns to login.
- Route guards respect auth state.
