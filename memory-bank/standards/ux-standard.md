# UX/UI Design Standard

## App Feel
- Calm, warm, spiritual
- Minimal clutter; premium spacing
- Smooth transitions/animations

## Accessibility
- All text ≥ 14sp
- Sufficient color contrast
- Descriptive alt text for all images

## Components
- Rounded corners (8px min)
- Soft gradients, glassmorphism accents

## Navigation
- Bottom bar for main sections
- Use FABs sparingly
